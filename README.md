# The ABC Pro — DEV preview

Independent preview of the five landing pages. This repository does not deploy to Cloudways or modify the original website.

Includes mobile logo carousels, desktop white logos, vector Yelp artwork and enlarged BBB.

Local: npm ci, then npm run dev.
GitHub Pages: https://diegohernan1994.github.io/the-abc-pro-dev/

The form uses the existing theabcpro.com lead endpoint from GitHub Pages. Submitting a form can send a real lead. No PHP backend, credentials, .env files, or SFTP deployment scripts are included.
